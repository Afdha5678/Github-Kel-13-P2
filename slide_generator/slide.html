Proses Integrasi

  • Arsitektur Sistem: Frontend (Next.js) dan Backend API (Express.js) terpisah, terintegrasi via REST API menggunakan Axios.
  • Autentikasi: Menggunakan JSON Web Token (JWT) dengan validasi role (Pemilik, Admin, Apoteker).
  • Database Connection: Prisma ORM dikonfigurasi melalui file .env untuk terhubung ke PostgreSQL.
  • Penyimpanan File: Gambar/berkas disimpan di server backend (statis).
  • Deployment: Di-deploy secara terpisah (*microservices*) menggunakan cloud Railway.
// authController.ts const token = jwt.sign( { id: user.id, role: user.role }, process.env.JWT_SECRET!, { expiresIn: '1d' } ); return res.json({ token, user });
